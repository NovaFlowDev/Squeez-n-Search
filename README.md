# Squeez-n-Search

Squeez N Search is an AI-powered research assistant that helps users:

- Explore academic papers
- Retrieve relevant evidence
- Compare research findings
- Generate answers with verifiable source citations

The project is built around Retrieval-Augmented Generation (RAG) to improve the reliability and traceability of AI-generated answers.

## Roadmap

Future development will focus on:

- Controlled agent capabilities
- Systematic evaluation
- Production-oriented engineering practices

## Technology Stack

- Python
- Sentence Transformers
- ChromaDB
- LLMs
- Streamlit
- FastAPI
- PostgreSQL
- Docker
